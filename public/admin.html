Connect Google (calendar + email)
  1. Google Cloud Console → APIs & Services → Credentials.
  2. Enable the Google Calendar API and the Gmail API, then create an OAuth client ID for a Web application.
  3. Add the redirect URI above as an authorised redirect URI.
  4. Paste the client ID and secret, save, then connect.
  5. The app looks for All Fired Up Deliveries, or creates it.
